# angry_milkyfrog

https://arickzhou-ai.github.io/angry_milkyfrog/

這是一款以物理拋射為主的 2D 關卡遊戲，共有 1 到 5 關。玩家會在左側操作夥伴進行瞄準與發射，透過撞擊箱子與敵人、或讓敵人摔落地面來通關並解鎖下一關。

遊戲玩法

。流程操作：從主選單進入說明／選關畫面，選擇已解鎖的關卡開始挑戰（全破 5 關後可回到主選單重玩）。

。瞄準與發射：在遊玩畫面中按住滑鼠左鍵拖曳瞄準，畫面會顯示 5 個白色預測軌跡點；放開左鍵後，夥伴會依拉扯方向與力道飛出並受重力影響。

。擊敗敵人與關卡條件：每關提供 3 位夥伴依序上場；讓夥伴撞上敵人或使敵人高速摔落地面即可觸發爆炸淘汰。關卡內所有敵人都被消滅即算過關並解鎖下一關；若 3 位夥伴用完仍有敵人存活，則會重設本關。

。第二關中，不同長相的夥伴具有分裂功能，當射出後點第二下，會分裂成兩個小夥伴

。第二關中長得像黑板的物件為障礙物，當夥伴碰撞到後會反彈
